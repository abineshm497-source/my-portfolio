## ⚙️ Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/abineshm497-source/my-portfolio.git
   cd my-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local development server:**
   ```bash
   npm run dev
   ```

4. Open your browser at `http://localhost:3000`.
